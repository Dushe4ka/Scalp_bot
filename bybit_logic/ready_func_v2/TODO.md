## 📋 Описание задачи

Реализация автоматической торговой системы для **шорт позиций** со следующими функциями:
- Вход в шорт (Sell позиция)
- Мониторинг цены и установка БУ при достижении 3% прибыли
- Трейлинг стоп с шагом 1%
- 3 лимитных ордера для усреднения (каждые 10% падения цены)
- Проверка открытости позиции (остановка торговли при закрытии)

## 🔍 Особенности реализации для шорта

### Отличия от лонга:

1. **Расчет процентов:**
   - Лонг: `(current - entry) / entry * 100`
   - Шорт: `(entry - current) / entry * 100`

2. **БУ (безубыток):**
   - Лонг: БУ чуть ниже текущей цены
   - Шорт: БУ чуть выше текущей цены

3. **Лимитные ордера:**
   - Лонг: ордера ниже цены входа (на падение для усреднения)
   - Шорт: ордера ниже цены входа (на падение для усреднения) ✅ ТО ЖЕ САМОЕ

4. **Стоп-лосс:**
   - Лонг: стоп ниже цены входа
   - Шорт: стоп выше цены входа

5. **Трейлинг стоп:**
   - Лонг: отслеживает рост цены вверх
   - Шорт: отслеживает падение цены вниз

## 📝 Дополнительные заметки

### Важные моменты:

1. **Всегда использовать `avgPrice` из позиции** - это реальная цена входа после усреднений

2. **Отслеживание изменений позиции обязательно** - лимитные ордера могут сработать в любой момент

3. **Проверка открытости позиции** - при закрытии стоп-лоссом или вручную, нужно остановить торговлю

4. **Универсальность кода** - количество лимитных ордеров может быть любым (3, 5, 10...)

5. **Логирование** - все важные события должны логироваться для отладки
